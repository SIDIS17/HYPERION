# Contribuer à HYPERION

Merci de votre intérêt pour le projet HYPERION.

## Flux de contribution

1. Créer une branche dédiée :
   - `feature/<nom-fonctionnalite>` pour une nouvelle fonctionnalité
   - `fix/<nom-correctif>` pour une correction
   - `docs/<sujet>` pour la documentation
2. Implémenter les changements de manière claire et documentée.
3. Ajouter ou mettre à jour les tests/documentation si nécessaire.
4. Ouvrir une Pull Request avec une description précise :
   - contexte et objectif
   - changements apportés
   - résultats de validation/tests

## Bonnes pratiques

- Garder des commits atomiques et explicites.
- Documenter les hypothèses, modèles et paramètres utilisés.
- Ne pas inclure de données sensibles ou propriétaires sans autorisation.
- Privilégier des scripts et résultats reproductibles.

## Validation

Avant de soumettre une contribution :

- Vérifier que le code s'exécute sans erreur.
- Exécuter les tests disponibles.
- Mettre à jour la documentation concernée.
